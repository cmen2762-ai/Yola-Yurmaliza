Instal Aplikasi ADMOPS

Pasang Aplikasi Langsung

Gunakan aplikasi ini seperti aplikasi native tanpa perlu membuka browser lagi. Akses cepat dari layar HP Android maupun desktop Laptop Anda!

Cara Manual Memasang Aplikasi:

Android

Buka menu titik tiga (⋮) di kanan atas Chrome HP, lalu pilih "Tambahkan ke Layar Utama" atau "Instal Aplikasi".

Laptop/PC

Klik ikon instal (⊕) di sebelah kanan address bar Chrome/Edge bagian atas.
